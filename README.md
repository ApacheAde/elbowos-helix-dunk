# Helix Dunk

Full-colour Python 3 neon gravity-basketball arcade for [ElbowOS](https://x.com/ElbowOS).

Slide under a drifting rim. Charge a shot. Orange wells pull the ball; the cyan well shoves it away. Dunks stack a streak. Airballs reset it.

A / D move and aim. Hold Space / W to charge, release to shoot.

## Play

```
pip install -r requirements.txt
python3 helix_dunk.py --play
```

## Record a 9:16 reel

```
python3 helix_dunk.py --record
```

Writes `/home/workdir/artifacts/HelixDunk_ElbowOS.mp4` (1080x1920, 15s, 30fps, h264).
